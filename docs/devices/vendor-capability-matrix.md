# Vendor Capability Matrix

## Vendor

Record the vendor or product line being evaluated.

## Push Support

State whether the vendor supports push-style delivery, and under what
conditions if known.

## Polling Support

State whether polling is supported, and whether the polling surface is local,
cloud-based, or not yet discovered.

## API Support

Describe whether a documented API exists, what style it uses if known, and
whether access appears official, partner-only, or inferred.

## Local Gateway Need

Capture whether current evidence suggests:

- definitely required
- probably required
- probably not required
- definitely not required
- not yet discovered

Tie the conclusion to evidence, not preference.

## Notes

Record firmware caveats, certification constraints, site-local assumptions,
multi-tenant concerns, or unanswered vendor questions.
