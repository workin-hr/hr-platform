# Attendance Device Model And Firmware Inventory

## Vendor

Record the device vendor name as observed in contracts, device UI, installer
notes, or support material.

## Model

Capture the model identifier exactly when possible. If only a family or series
is known, record that uncertainty.

## Firmware

Record the firmware version or note `Not yet discovered` if unavailable.

## Integration Pattern

Describe how the device currently appears to integrate, such as:

- push callback
- polling
- local network protocol
- vendor cloud API
- manual export/import

## Network Constraints

Capture site-local requirements, internet dependency, inbound callback needs,
VPN assumptions, static IP expectations, or firewall sensitivity.

## Evidence

Link the device manual, support note, installer evidence, screenshot, vendor
spec, or runtime behavior that supports the entry.
