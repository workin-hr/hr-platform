# Risk Register

## R-001 Legacy False Assumptions

Discovery may incorrectly simplify PHP behavior or production-only coupling.

## R-002 Flutter Contract Drift

API changes may break mobile or desktop clients if compatibility evidence is weak.

## R-003 Migration Underestimation

MySQL features, procedures, or operational patterns may complicate the PostgreSQL migration more than expected.

## R-004 Attendance Device Variability

Device protocols, firmware differences, and vendor limitations may expand edge integration scope.

## R-005 Governance Weakness

If rulesets, review requirements, and team ownership are not applied early, unsafe practices may spread before discovery begins.

## R-006 Agent Boundary Erosion

Without explicit constraints, planners may drift into implementation or reviewers may lose independence.
