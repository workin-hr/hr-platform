# Bootstrap Risks

## R-001 False Certainty

Making architecture, migration, or compatibility decisions before legacy discovery would create expensive rework.

## R-002 Agent Scope Creep

Without explicit boundaries, planning agents may become implementation agents and reviewing agents may lose independence.

## R-003 Governance Drift

If GitHub rulesets, team boundaries, and approval requirements are delayed, early repository activity may normalize unsafe workflows.

## R-004 Toolchain Prematurity

Installing too many platform tools before validated need may add maintenance cost without improving bootstrap quality.

## R-005 Hidden Legacy Complexity

Legacy PHP behavior, database coupling, and Flutter contract assumptions may be more complex than current high-level descriptions suggest.
