# Local Bootstrap Tools

## Commands To Install Later When Approved

- `uv tool install specify-cli`
- `npm install -g markdownlint-cli2`
- `pip install yamllint`
- package-manager install for `shellcheck`, `actionlint`, `gitleaks`, and `lychee`

## Current Local Verification Position

The repository scripts must run with the tools currently available. Additional linters and scanners are optional until humans approve their installation.

## Phase 0 Rule

Do not silently install network dependencies. Document the command first and obtain human approval for the bootstrap toolchain.
