# Security Documentation

Use this area for tenant isolation requirements, threat models, secrets boundaries, access policies, secure-development rules, and security review evidence.

## Current Status

- `security-boundaries.md`, `logging-and-privacy.md` — principle-level rules, in effect now.
- `threat-model.md` — template and method only. **Not started — pending Discovery.** Do not treat this repository as having a completed threat model; it does not.
- Access policies and secure-development rules beyond what `security-boundaries.md` states are not yet written; they depend on the authentication/authorization direction in ADR-0005, which is currently Proposed.
