# Migration Discovery

Use this area for MySQL-to-PostgreSQL discovery, schema inventory, data-risk notes, migration strategies, cutover assumptions, and validation plans.

These are discovery templates, not fabricated inventories — every file here
is header-only until real Discovery evidence is gathered. Do not fill in
production facts, row counts, or dates without a cited source.
