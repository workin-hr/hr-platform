# MVP Scope Prioritization

## Candidate Capability

Record the feature, workflow, or operational capability being prioritized.

## Customer Value

Describe the direct user or buyer value. Prefer concrete outcomes over generic
importance labels.

## Delivery Risk

Capture implementation uncertainty, migration complexity, contract risk,
integration risk, or operational burden.

## Dependency Risk

Record what must be true first, such as legacy discovery, device evidence,
approved ADRs, or prerequisite platform capabilities.

## Recommended MVP Position

Classify the recommendation clearly, such as:

- core MVP
- MVP if evidence confirms
- post-MVP
- discovery first / not ready to position

Include the reason for the recommendation in the same entry.
